# Third-party dependencies

The application is MIT licensed. Dependencies retain their own licenses and notices. Exact package versions and license metadata are recorded in `composer.lock` and `package-lock.json`. Runtime dependencies include Symfony components (MIT), Doctrine (MIT), League OAuth2 Server/CommonMark (MIT/BSD where specified), Twig (BSD-3-Clause), Webklex PHP IMAP (MIT), and the MCP SDK (MIT). Tailwind CSS is MIT licensed.

Before distributing dependencies, include their supplied license files. The public source export contains manifests and locks, not vendor or node_modules. `composer licenses` lists installed Composer license declarations; inspect individual dependency notices for redistribution.
